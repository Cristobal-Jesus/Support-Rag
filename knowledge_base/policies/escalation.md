# Escalado a soporte — empresa ficticia NexoDemo

## Información necesaria en un ticket

Incluye un resumen del problema, el código de error, la hora aproximada, si el equipo es corporativo o personal y los pasos que ya has probado. Evita contraseñas, códigos de autenticación y capturas con datos sensibles. El objetivo es que soporte pueda reproducir y clasificar la incidencia.

## Prioridad de la incidencia

Si una incidencia impide trabajar a un único usuario y no existe alternativa, se clasifica como prioridad alta. Si afecta a varios usuarios de un servicio corporativo, soporte debe valorar una incidencia general. Esta guía no define tiempos de resolución garantizados ni permite prometer que el problema se resolverá antes de una reunión.

## Cuándo interviene una persona

Una persona autorizada debe intervenir para restablecer el segundo factor, conceder acceso al escritorio virtual o revisar una cuenta que continúa bloqueada. Si el procedimiento no está documentado o las fuentes se contradicen, consulta a soporte. El asistente prepara la información y explica los pasos documentados; no ejecuta cambios en sistemas reales.
