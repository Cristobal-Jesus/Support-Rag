# Manual de VPN — empresa ficticia NexoDemo

## Configurar la VPN corporativa

En un portátil corporativo administrado, abre el catálogo interno de aplicaciones e instala NexoVPN. Selecciona el perfil «NexoDemo corporativo», introduce tu usuario de empresa y confirma el segundo factor de autenticación. Cuando el estado sea «Conectado», vuelve a abrir la aplicación interna. Antes de instalar, consulta la política de dispositivos personales: tener el instalador no autoriza a conectar cualquier equipo.

## Revisar una conexión fallida

Si la VPN no conecta, comprueba primero que puedes navegar por Internet, revisa la fecha y la hora del equipo y cierra y vuelve a abrir NexoVPN. Anota el código exacto del error y consulta el manual de errores frecuentes. No desactives el cortafuegos ni el antivirus para intentar conectarte.

## VPN conectada pero aplicación inaccesible

Si la VPN aparece conectada pero una aplicación interna no abre, desconecta y conecta la VPN una vez y vuelve a probar. Si continúa el problema, recoge el nombre de la aplicación, la hora y el mensaje de error, y solicita ayuda a soporte. Este documento no contiene direcciones de servidores, claves ni pasos para modificar rutas de red.
