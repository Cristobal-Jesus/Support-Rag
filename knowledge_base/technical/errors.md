# Errores frecuentes — empresa ficticia NexoDemo

## Error VPN E101: credenciales rechazadas

El código E101 significa que se han rechazado las credenciales. Comprueba el usuario de empresa y que el bloqueo de mayúsculas no esté activado. Si has olvidado la contraseña, utiliza el procedimiento de recuperación de acceso. No repitas intentos de forma indefinida: cinco intentos fallidos bloquean la cuenta durante quince minutos.

## Error VPN E202: segundo factor caducado

El código E202 indica que ha caducado la solicitud de segundo factor. Inicia una conexión nueva y aprueba únicamente la solicitud que acabas de generar. Si no tienes acceso al dispositivo de autenticación, solicita a soporte que verifique tu identidad y restablezca el segundo factor. No compartas códigos de autenticación.

## Error VPN E303: dispositivo no administrado

El código E303 indica que el dispositivo no está administrado por NexoDemo. Utiliza un portátil corporativo administrado o consulta con soporte el estado de inscripción de tu equipo. Instalar de nuevo el cliente VPN no convierte un ordenador personal en un equipo autorizado. Consulta la política de dispositivos personales para conocer las alternativas.
